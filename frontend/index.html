What is VoxCampus?

VoxCampus is an AI-103 Group Project at Chitkara University. It's a voice-first university assistant that helps students get instant answers about courses, admissions, fees, exams, and faculty.

Students waste time searching across websites and offices for basic information. VoxCampus solves this with a single, intelligent, conversational interface — powered by Azure AI and a RAG pipeline for accurate, grounded responses.

🎙️ Voice Input 🤖 AI Answers 📚 RAG Grounded 🔊 Voice Output
❌ Problem

  • Visiting different offices
  • Unclear fee information
  • No single source of truth
